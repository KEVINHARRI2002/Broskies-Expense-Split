# Split - Shared Expense Ledger

A simple web application for managing shared expenses within a group. It helps track who paid for what, calculates each member's share, determines balances, and generates the minimum number of transactions required to settle expenses fairly.

## 🌐 Live Demo

👉 **https://kevinharri2002.github.io/Broskies-Expense-Split/**

## Features

- Add and manage group members
- Record shared expenses
- Automatically calculate each member's share
- Display amount paid versus actual share
- Show who owes money and who should receive money
- Generate optimized settlement transactions
- Simple, clean, and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/kevinharri2002/Broskies-Expense-Split.git
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

No installation, dependencies, or server setup is required.
